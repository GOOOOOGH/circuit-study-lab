# 电路研习室：本地开发依据

版本：2.1 ｜ 更新：2026-10-13 ｜ 状态：全纲条目首版讲义已编写；指定教材正文校核与真实项目验证状态单列。

本项目面向硬件开发、电路设计、AI 应用硬件与机器人系统学习。以大学教材建立基础，以器件、电路、动画、实验和项目连接实际工程工作。

## 克隆和运行

目标公开仓库：https://github.com/GOOOOOGH/circuit-study-lab 。需要Node 20.19+或22.12+和pnpm：

```sh
pnpm install --frozen-lockfile
pnpm run build
pnpm run test
pnpm run dev
```

详细操作见[GitHub源码与运行说明](docs/09-GitHub源码与运行说明.md)。生成缓存由构建重建，现有Sites身份不包含在这个导出中。五套项目ZIP由构建生成，不作为GitHub源文件提交。macOS如需使用双击启动文件，先运行 `chmod +x 启动网站.command 生成网站.command`；也可以直接使用上面的pnpm命令。

## 使用方式

1. 直接修改对应 Markdown 文件并保存；编辑器或普通文本工具均可。
2. 让开发代理读取本项目，执行“按本地大纲和架构更新网站”。
3. 代理检查变更影响，更新页面、课程关联、实验和测试，再交付结果。

本地规划是开发依据，不是教材全文。已实现目录同步与构建工具：启动开发服务时自动读取规划，监听 docs/ 与 content/ 修改；构建时重新生成课程地图、导航、实验索引和来源。新讲义、动画和复杂功能仍需要开发与核对，不能由目录自动推导。重新生成不等于准确性审核通过。

## 启动与生成

- 在 macOS 上双击 `启动网站.command`，然后访问 http://127.0.0.1:5173/ 。停止服务时在终端按 Ctrl+C；端口已占用时不要重复启动。
- 双击 `生成网站.command`，会校验 TypeScript 并生成 `dist/`。
- 终端方式：`node scripts/run.mjs dev`、`node scripts/run.mjs build`、`node scripts/run.mjs test`。
- 本机启动文件支持已发现的 Codex Node 运行时；其他电脑需 Node 20.19+ 或 22.12+ 并安装项目依赖。依赖版本由 pnpm-lock.yaml 固定。
- 不建议直接双击 dist/index.html；使用本地服务器或站点部署。

## 总体学习结构

共同基础 → 大学主干课程 → 器件与典型电路 → 通用工程能力 → AI 与机器人专业路线 → 综合项目 → 就业能力与研究拓展。

大学主干课程中的模电、数电必须完整保留；专业路线优先服务 AI 应用硬件和机器人，FOC 与充放电/BMS 是执行系统和能源系统的核心专题。
