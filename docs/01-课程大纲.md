# 01 课程大纲

版本：1.0 ｜ 更新：2026-10-12

## 1. 定位与学习目标

面向从基础逐步进入硬件开发的学习者，核心应用为人工智能设备和机器人系统。最终能解释原理、计算与选型、设计原理图和 PCB、进行测量与故障定位，并形成工程验证与产品交付资料。

AI 应用重点是感知、边缘推理和硬件系统落地；模型训练仅提供必要背景，不以大模型训练或通用 AI 软件课程替代硬件课程。

全体系覆盖通用硬件岗位的主要能力，再分方向深入，不声称囊括所有行业或产品的全部要求。

## 2. 教学层次与编号

- F：基础支撑；A：模拟电子；D：数字电子；C：信号与控制。
- E：器件教学；G：通用工程；T：专业路线；P：项目。
- ID 是稳定引用，不因排序改变而重编号；课程名称可改。删除 ID 前处理依赖。
- “先修”是建议学习依赖，不是用户必须完成后才能访问的权限锁。
- 以下为规划范围，不代表讲义已完成或验证通过。
