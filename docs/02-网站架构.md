# 02 网站架构

版本：1.0 ｜ 更新：2026-10-12

## 1. 产品结构

网站名称暂定“电路研习室 / Circuit Lab”。中文为主，术语提供英文对照。风格是清晰、克制的学习工作台，优先保证公式、波形、电路图和长文可读，不建设营销首页。

| 导航 ID | 一级入口 | 内容与行为 |
| --- | --- | --- |
| N01 | 学习地图 | 共同基础与专业依赖、阶段目标、推荐下一课、路线选择 |
| N02 | 系统课程 | F/A/D/C/G 全部课程；章节索引、学习状态、先修链接 |
| N03 | 器件与电路库 | E 家族、典型电路、参数/选型/应用；关联课程与案例 |
| N04 | 交互实验室 | 动画、参数、波形、计算器、逻辑与控制实验 |
| N05 | 工程工作台 | 按企业流程查找模板、检查表、文件交付与测试方法 |
| N06 | 项目与案例 | P 系列项目、厂商方案、工程分析、近期应用 |
| N07 | AI 与机器人路线 | T01—T07 优先；就业任务、项目与研究；其他路线入口 |
| N08 | 资料与来源 | 教材、手册、应用笔记、标准信息、文献、术语与勘误 |
| N09 | 我的学习 | 进度、收藏、笔记、练习与复习；说明本地存储范围 |

全站搜索支持标题、术语、器件、课程与来源；按层级、方向、类型和内容状态筛选。搜索没有结果时显示真实空状态，不捏造内容。

## 2. 页面模板

### 课程页

标题/ID/内容状态 → 目标与先修 → 问题引入 → 原理/定义/公式/条件 → 推导与例题 → 交互实验 → 工程迁移 → 常见误区 → 练习反馈 → 来源 → 下一步。

### 器件页

原理 → 符号/曲线 → 模型 → 典型电路 → 数据手册 → 参数/计算/选型 → PCB/测量/故障 → 近期应用 → 关联课程。

### 实验页

实验目标 → 模型与假设 → 电路/状态动画 → 参数与单位 → 数值/曲线 → 暂停/单步/重置 → 观察任务 → 解释 → 适用边界与来源。

### 项目页

需求与指标 → 先修与设备 → 架构 → 设计计算 → 原理图/PCB → 软件或控制 → 调试 → 测试计划/结果 → 问题与修订 → 交付物。

### 方向页

典型系统 → 岗位任务 → 先修地图 → 分阶段技能 → 项目 → 工具/交付物 → 研究问题与文献。不得把技术介绍包装成已核实的就业行情。

### 工程工作台

需求、架构、选型、原理图、PCB、制造、装配、上电、性能、EMC、可靠性、试产量产，每阶段提供目标、输入、步骤、评审点、输出与常见问题。

## 3. 内容模型与稳定关联

规划 Markdown 是范围与架构依据，正式讲义是独立内容文件；不能仅凭大纲生成未经核对的详细教材。

| 实体 | 必要字段 |
| --- | --- |
| module | id、title、summary、priority、prerequisites、lessonIds、status |
| lesson | id、moduleId、objectives、prerequisites、sections、sourceIds、experimentIds、questionIds、status、reviewedAt |
| device | id、familyId、principle、models、parameters、applications、limitations、sourceIds、relatedLessonIds |
| experiment | id、title、modelType、assumptions、parameterSchema、units、outputs、controls、sourceIds、testCases |
| case | id、type、publishedAt、retrievedAt、deviceIds、conditions、claims、limitations、sourceIds、verificationStatus |
| track/project | id、title、prerequisites、steps、deliverables、relatedIds、status |
| source | id、title、author/publisher、edition/version、url、locator、publishedAt、retrievedAt、type |

缺失的日期用“来源未提供”，不得猜测。status 建议：planned、draft、reviewed、published；只有发布且通过相关验证的内容可标记为可学。进度以稳定 lesson ID 存储，与标题和导航顺序解耦。

## 5. 技术架构（开发目标）

- 默认采用静态可部署前端，复杂学习界面使用 React + Vite + TypeScript；具体依赖版本实施时核对。
- 课程内容与 UI 分离；Markdown 正文与结构化元数据经校验后加载，组件不硬编码整套课程。
- 公式使用可访问的数学渲染；电路/矢量图优先 SVG，波形按需求使用 SVG/Canvas。教学图不得依赖生成图片保证数值准确。
- 实验采用独立计算模型和渲染组件；必要时高级仿真使用明确的外部工具流程或后续专用引擎。
- 第一版无需服务器、账户、收费或模型 API；学习记录本地保存，提供导入/导出，读取写入失败时提示。
- 后续账号/同步/自动更新需先更新此文件，不自动引入。
- 不将外部网页实时内容直接作为已审阅课程；来源链接失败不应导致本地课程无法阅读。

### 已采用目录

```text
docs/                本地规划依据（本次已保存）
content/             讲义、器件、项目、案例、来源与元数据
src/components/      复用页面与交互组件
src/experiments/     数学模型、动画、参数和测试
src/lib/             搜索、关联、进度、迁移与内容校验
public/              可发布的静态资源
dist/                构建输出，禁止手工作为内容源修改
```

## 6. 重新生成机制

读取最新规划 → 分析变更 → 校验 ID/依赖 → 更新内容清单与实现 → 内容和交互验证 → 构建本地网站 → 报告差异与限制。

标题/排序变化不清除进度；删除课程保留记录或显式迁移，避免自动丢弃。用户笔记、进度、导出文件和原有素材不作为可覆盖的生成输出。

第一阶段已实现 Markdown 表格解析、目录校验与构建，开发服务监听 docs/ 和 content/；可以重建导航、模块/方向/项目、实验索引和来源。讲义保存在 content/lessons.json，实验在 src/experiments/ 与组件中实现。修改大纲不会自动写出新讲义或动画，详细内容仍需核对及实现。

## 7. 验收

### 第二轮课程建设要求

按大纲顺序显示讲义与前后课；首页从 F01 开始，不能继续推荐越过基础的专业课。课程页补充来源定位、适用条件、完整算例、单位/守恒检查、误区、两道练习和逐节导航。无合适交互模型的数学课使用观察任务与手算练习，不挂接无关实验。

reviewed 表示本项目已对列明的来源事实、推导、算例和题目做核对；不表示外部专家背书或所有工程条件均成立。模电/数电样板未完成指定教材逐节校核时继续标 draft。来源记录必须给出具体位置与核对范围。

- 所有导航可用，无死链、假按钮和冒充完成的占位课。
- 本地大纲中的模块完整可追踪；未完成标注状态。
- 公式/参数/例题/模型通过内容规范；实验结果符合模型且边界可控。
- 主要流程：选路线 → 上课 → 调实验 → 做练习 → 保存进度 → 返回继续。
- 桌面/手机可读，无关键内容溢出；键盘、焦点、标签、对比度和动画替代可用。
- 更新不覆盖本地笔记与进度；来源、时间和验证状态可检查。

### 第三轮建设：F03/F04

F03 按 C、L、初始条件、RC、RL、RLC、正弦量、相量阻抗、谐振、频率响应、交流功率组织；F04 按万用表、示波器、电源、电子负载、逻辑分析仪、探头、接地、误差与记录组织。保留旧 L-F03-01 和原首题答案 ID，讲义 order 与稳定 ID 分开。X02 支持 RC/RL 和有限初值，X16 的零初值限制明确。课程地图显示真实建设进展，planned 仍保留；下一待建设模块为 A01。测量只用低能量教学案例，具体仪器连接查型号手册。

### A01增量（2026-10-13）

新增 crosschecked 状态：原理与原创算例已交叉核对，指定教材正文仍待核对，不能转换成 reviewed。书目文件 content/textbooks.json 随构建进入来源页。X03 已实现三个PN结偏置状态切换及固定300 K二极管指数曲线/负载线工作点；模型不表示真实器件或粒子仿真。A01 当前仅有前六节，模块未完成；后续按顺序补充BJT、JFET和MOSFET。

## 全纲实现架构（2026-10-13）

讲义分组保存在content/courses/*.json，原有content/lessons.json保持稳定ID和答案。器件、路线和项目页均能进入实质讲义，项目附可下载设计任务、计算/验证表与复现步骤，不冒称实际制板和实测完成。coverage.json逐模块保存知识点到讲义/段落的关联；sources-research.json保留核对定位和边界；cases.json与glossary.json提供案例与术语。页面状态分开显示覆盖、计算验证和教材正文校核。新课程采用crosschecked仅标列明原理资料，不伪称整本教材审阅。所有动画使用有明确条件的独立数学模型；参考设计案例注明未在本项目硬件复现。按需拆分课程数据与实验代码以保持首屏性能。

### 实现与验收更新

课程按需从public/curriculum读取，索引与React运行时分包，实验代码按需加载。系统减少动态偏好停用连续播放并保留单步，实验也有“减少连续动态”开关。项目模板和可运行包在public/projects；构建时依据现有任务源和模型重新打包，不能从标题自动生成真实硬件方案。全纲清单是内容位置索引，不把有讲义当教材/实物审核完成。

### 2.1 器件与基本放大深化

X03保留PN结/二极管，增加BJT带载分压Q点与共射小信号、JFET自偏置可接受根、增强型NMOS工作区。工作区检查失败时不得把候选解显示成真实饱和解；波形只展示有效Q点的小信号预测，并明确摆幅越界。模型、内容和来源定位分别维护；旧ID和本地学习存储不改。

## 2.2 深度教学页面

lesson新增可选teaching字段（问题、适用条件、图解类型、分步过程、关联扩展阅读）与experimentMode；section可选figure图解。先预测再看图、点击分步展开推导、独立算例、调整参数看波形与失败提示。教学图使用本站SVG，图中节点/方向与文字模型一致；不复制参考博主视频帧。旧课保持可读，未升级课显示原有范围，不暗示全站都达到详细课标准。X04增加级间加载、差分电流/共模模型与运放输出约束；独立计算模型注明教学假设。
