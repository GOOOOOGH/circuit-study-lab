# 03 内容质量与来源规范

版本：1.0 ｜ 更新：2026-10-12

## 1. 原则

目标是准确、可核查、可修正，不能承诺未经验证的“绝对无误”。课程以大学教材为理论依据，用原创讲解、推导和例题组织；不复制整章教材、习题集或受限图片。

知识点注明定义、单位、参考方向、假设与适用范围。理想化内容明确标记，再逐步加入温度、寄生、容差、带宽、损耗和负载。

## 2. 发布前核对

每节基础课：核对教材版本和位置 → 核对定义/公式/推导 → 检查量纲/符号/边界 → 独立计算例题 → 验证动画和题目解释 → 记录审阅日期。

出版社目录只能核实覆盖范围，不能代替逐节内容核对。F01–F04 讲义按各节记录核对来源、范围和算例；模电、数电仍待指定教材逐节校核。不得生成虚构页码或声称教材全文审核。

工程案例：保留具体器件、输入输出、频率、负载、温度、布局与测量条件。厂商参考设计不等于在其他板卡上自动成立。论坛技巧需交叉核对，不作为基础定律的唯一依据。

研究案例：标明论文/预印本，区分仿真、台架与产品结果；记录基线、指标、适用对象和局限。未知状态写未知，不推断已同行评审。

## 3. 必须防止的误导

- 欧姆定律的线性电阻模型不能直接套用所有非线性器件。
- 运放“虚短/虚断”要注明负反馈、线性运行等条件；饱和和动态限制单独解释。
- BJT 与 MOSFET 的工作区名称不混用；MOSFET 低损耗导通开关通常在线性区。
- 采样率与 ADC 位数不等于系统真实带宽和精度。
- 高速不能只看时钟频率；边沿与互连电气长度也关键。
- 接地分割、磁珠、屏蔽和滤波不是普适解法；必须分析回流及耦合路径。
- 不把不同电池体系、型号的充电阈值和策略混为通用参数。
- FOC 的坐标、符号、角度与电机约定前后一致，解耦关系注明模型条件。
- 教学动画不冒充 SPICE/场求解/硬件实测；示意波形明确标识。

## 4. 来源优先级与时效

基础：指定教材 → 其他大学教材/课程用于交叉核对。

器件/工程：当前数据手册、勘误、厂商应用笔记、参考设计、官方工具文档；标准要求查适用产品/地区/版本。

前沿：近期官方技术资料和原始论文。个人经验标为补充，记录出处与验证状态。

“最新应用”限定为“截至某检索日期收集的近期应用”，不声称穷尽最新成果。记录发布日期与检索日期；搜索引擎抓取日期不能代替原文发布日期。不设置后台自动更新或定期任务，除非用户另行要求。

就业岗位映射是教学规划；招聘数量、薪资、行业热度需要新的带日期来源，不能从厂商宣传推导。
