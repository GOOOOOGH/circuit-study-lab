## 1. 修改入口

| 你要改什么 | 编辑文件 | 示例 |
| --- | --- | --- |
| 增减知识点、调整课程和先修 | 01-课程大纲.md | 给 T02 加入某种电流采样方案 |
| 改专业优先级、项目或岗位方向 | 01-课程大纲.md | 将 T08 改为 P1，新增配套项目 |

| 改生成流程与维护习惯 | 本文件、必要时 AGENTS.md | 增加内容校验或新的交付要求 |

直接编辑 Markdown 表格和段落即可，不需要修改网站代码。保留 ID，修改标题和内容；新增条目使用未占用 ID。ID 不是排序编号。

## 2. 修改示例

给 FOC 添加专题：在 01 文件的 T02 核心内容加入“单电阻/双电阻/三电阻采样的窗口与重构”；在 02 文件 X09 加入对应的采样窗口可视化；给 03 文件补充具体官方资料。不要仅改页面文案而保留不一致的模型。

更改专业优先级：修改 T 表优先级，同时检查实施顺序和关联项目。不删除已完成的共同基础。

删除模块：先搜索该 ID 的引用，更新先修、项目和页面关联。已有用户学习记录保留或迁移，不静默清空。

## 3. 重新生成请求

修改后可以使用：

> 请读取 circuit-lab/README.md、AGENTS.md 和 docs 下的四份规划文件，以本地最新版本为准更新网站。先检查变更和依赖，再实现受影响内容，保留学习记录，报告完成项与未完成项。本次仅在本地生成和预览，不发布。

若要首次开发：

> 请按照 circuit-lab 中的本地大纲和架构开发第一阶段网站。保留完整课程地图，先完成基础、模电、数电教学样板和交互机制，专业方向以 AI 与机器人为优先。未完成内容明确标注，基础讲义按来源规范核对。本次仅在本地开发和预览。

可以把最后一句换成明确的发布要求。第一阶段已经实现目录同步与本地构建工具；修改本地文件不会自动部署。

### 当前可以直接操作

1. 双击项目中的“启动网站.command”，在 http://127.0.0.1:5173/ 预览。服务运行时，修改 docs/ 和 content/ 会同步目录并刷新界面。
2. 修改 01 文件中的标题、内容范围、先修、方向优先级或项目交付物；修改 02 的导航/实验索引；修改 03 的来源表。
3. 双击“生成网站.command”，将最新内容生成到 dist/。目录和 TypeScript 校验失败会停止构建并说明原因。
4. 详细讲义编辑 content/lessons.json；新增动画、页面结构或实验计算仍交给开发代理实现，不能只改规划表就自动完成。

自动同步保留 ID、处理现有表格结构；大幅改变 Markdown 表格列结构时，需要同步修改 scripts/sync-content.mjs。来源表新增条目使用 Markdown 链接格式。

## 4. 开发代理每次必须做什么

1. 读取全部规划文件，检查与现有网站/内容的差异。
2. 汇总受影响模块、内容、实验、依赖和学习记录迁移。
3. 修复规划引用，更新讲义、索引、页面和实验；不得据大纲编造来源。
4. 对知识公式、数值、核心操作、响应式和内容状态进行适当检查。
5. 本地构建与预览，说明实现范围、测试和限制。
6. 在下面追加变更记录；发布按用户当次要求执行。

## 5. 完成判定

- 页面、知识点和实验与最新本地文件一致。
- 内容来源、模型条件和未完成状态真实。
- 新增和删除的关联没有死链。
- 标题或顺序变化不会清空学习记录。
- 新功能有可操作结果，而不是只出现一个按钮。
